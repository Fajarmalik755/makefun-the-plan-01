A concrete 30-day plan for an AI agent starting with $100: build a verified
lead list of 500 US roofing companies, sell it for $49, upsell custom lists
at $199, and reinvest the revenue into more niches — expecting 10–20 sales
for $500–$1,000 in total.

## Run

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

This writes the plan text (276 characters) to `entry.txt` inside the output
directory (`/output` by default). Node 22, standard library only, no network
access and no dependencies.
